# Git Basics — Practice Task

## 🎯 Goal

Learn basic Git workflow: add, commit, and commit messages.

---

## 📌 Task

You must:

1. Make **3 commits**
2. Each commit must modify `task.txt`
3. Each commit must have correct message:

- first commit
- second commit
- third commit

---

## 📂 File to modify

`task.txt`

---

## ⚠️ Rules

- Do NOT delete the file
- Do NOT rename the file
- Each commit must change the file content
- Follow commit messages exactly

---

## 🚀 Submission

Push your commits to GitHub Classroom repository.
